# 📬 TecnoSoporte-IA

**Automatización inteligente de gestión de correos de soporte**

TecnoSoporte-IA es una solución que **automatiza la recepción, clasificación y almacenamiento de correos electrónicos**, mostrando la información procesada en una **aplicación web** para su gestión y consulta.

---

## 🚀 Características

- 📥 Recepción automática de correos electrónicos  
- 🧠 Clasificación inteligente de emails mediante IA  
- 🗄️ Almacenamiento estructurado en base de datos  
- 🌐 Visualización de correos en una aplicación web  
- 🐳 Despliegue sencillo con Docker  

---

## 🧠 Flujo del sistema

1. El sistema recibe los correos entrantes  
2. Se analiza y clasifica el contenido automáticamente  
3. La información se guarda en la base de datos  
4. Los correos se muestran en la aplicación web  

---

## 🛠️ Tecnologías utilizadas

- **n8n** – Automatización de flujos  
- **Docker & Docker Compose** – Contenerización y despliegue  
- **Base de Datos** – Persistencia de la información, Postgres
- **Web App** – Interfaz para visualización de correos, vite, tailwind
- **IA Open-Source** – Clasificación y análisis de texto  

---

## 📦 Instalación

### 1️⃣ Clonar el repositorio
```bash
git clone https://github.com/Hferpi/TecnoSoporte-IA.git
cd TecnoSoporte-IA
```
### 2️⃣ Levantar los servicios
```bash
docker compose up --build
```

### 3️⃣ Acceder a la aplicación

Abre tu navegador en:

http://localhost:PUERTO


(El puerto depende de la configuración del proyecto)
